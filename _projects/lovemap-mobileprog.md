LoveMap is an Android Kotlin app built with Jetpack Compose, Firebase Auth, SQLite helpers, Google Maps API/Compose MapView, and Coil. It supports email login, location-tagged Todo items, map markers and detail views for posts, image-attached post create/edit/delete, and profile image/nickname settings.
